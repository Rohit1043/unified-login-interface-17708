# Ocean Professional Login UI (React)

This project provides a lightweight, responsive login page built with React and plain CSS, styled per the Ocean Professional theme.

## Features
- Centered, single-column layout with subtle gradient background
- Email/username and password fields with basic validation
- Prominent primary Login button with hover/focus states and transitions
- Remember me checkbox and a placeholder Forgot password link
- Sample credentials panel with copy-to-clipboard buttons
- Mock async submit (800ms) with success/error message
- Accessibility: semantic labels, aria-invalid, aria-describedby, focus rings
- Mobile-first responsive design
- No extra dependencies

## Run locally
- `npm start` and open http://localhost:3000

## Sample credentials
- username: `demo@example.com`
- password: `Demo@123`

Environment variables like `REACT_APP_API_BASE`, `REACT_APP_BACKEND_URL`, and `REACT_APP_FRONTEND_URL` are optional and are used only to display a target URL if set.
